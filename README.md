# Ecommerce Retrieval

电商视频商品识别：完整候选池检索与零训练精排实验脚本。

- [服务器拉取与更新](GITHUB.md)
- [精排运行说明](scripts/RERANK.md)
- [检索脚本说明](scripts/README.md)

精排流程：视觉 Top-10 与多模态 Top-10 并集 → 固定等权 RRF → Qwen3-VL-Reranker-2B 逐候选打分 → 100 条预跑 → 10,000 条评估。

候选生成不读取标签、不补真值；标签仅用于独立指标评估。报告完整系统 Top-1、候选内精排准确率、候选 Recall、视觉正确改错率及单视频耗时。

代码已通过本地语法和合成回归检查，GPU 精排尚待服务器实际执行。仓库不含数据、模型或实验产物。
